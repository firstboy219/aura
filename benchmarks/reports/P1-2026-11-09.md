## Owner-requested review: "is everything done so far powerful?" (2026-11-09)
Defects found and fixed after deployment:
1. Rejected provider calls (HTTP 402) were billed as $0.04 and the cause was invisible (`all_routes_failed`) → no charge for definite HTTP errors; `TASK_ERROR` event carries the redacted cause (`0605f54`).
2. False success: a plan that skipped the requested output still ended SUCCEEDED → objective-named outputs enforced in plan and completion check (`deeeb0a`).
3. Documented but not implemented: content purge (ADR-0008) and restore verification (Blueprint §10) → daily purge job and restore drill (`deeeb0a`).
4. ADR-0007 claimed a Core-checked 32 MiB scratch quota that did not exist → ADR corrected (bounded by the container tmpfs).

Strong today (implementation-verified): durable execution and crash recovery (20 SIGKILLs, no duplicate writes), capability and approval enforcement (hostile-worker test), SSRF and path safety, budget and kill switch, secret handling, small footprint.

Not powerful yet — by phase design (P2+), not defects:
- No verification or replanning: one failed step (e.g. a 404 page) fails the whole task; no partial result.
- No `web.search`: the objective must name the URLs; only three tools.
- No live progress stream or UI: CLI polling only; results are read with `docker exec … cat` (the P1 API has no file endpoint).
- One task at a time; free models are slow (≈ 23 s per RS-1) and rate-limited; private tasks need OpenRouter credit.
- Worker not OS-isolated until P4.

## Known gaps and risks
- Paid routes untested end-to-end (OpenRouter credit 0); private tasks cannot run until credit is added.
- Companion documents MISSING (ISLAMIC_CHARTER, RESEARCH_BENCHMARK, MODEL_ASSIGNMENT, KICKOFF); model profile is
  provisional (A-13); benchmark weights `TBD_OWNER`.
- Worker is not OS-sandboxed and shares the Core uid inside the container (ADR-0007, by design until P4).
- `write_external` recovery path has no P1 tool to exercise it (A-19).
- Provider key is shared with Jarvis (A-04); AURA's budget bounds only AURA's spend.
